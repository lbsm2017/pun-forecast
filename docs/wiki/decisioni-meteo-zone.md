# Decisioni: meteo per zona

Collegate: [Open-Meteo](fonte-open-meteo.md), [Flussi dati](decisioni-flussi-dati.md).

- **2026-11-17** — L'utente ha scelto un capoluogo per zona: Nord → Milano, Centro-Nord → Bologna, Centro(-Sud) → Roma, Sicilia → Palermo, Sardegna → Cagliari.
- **2026-11-17** — Proposti dal lead e approvati dall'utente: Sud → Napoli, Calabria → Catanzaro.
- **2026-11-17** — Pubblico: solo Milano. Locale: media delle 7 città con i pesi di domanda delle zone.
- **2026-11-17** — Il meteo è utile solo a 1–16 giorni (previsione Open-Meteo); oltre si usa la climatologia. Viene tenuto solo se il backtest migliora.
